# 上下文与工具执行

这些行为属于 Agent 的正常运行流程，不需要额外安装或开启一组功能。

用户输入 → 构造模型上下文 → 模型回复或调用工具 → 保存结果 → 下一轮。

- 文件修改可附带 `then_run`，成功修改后再执行命令；命令失败保留修改并反馈错误。
- 重复的大输出保留原文，在模型请求中按需替换为可召回引用；用户历史不被改写。
- 诊断日志按业务条件精简，使用已授权的当前模型，校验引用并保留原文；失败保留完整输出。
- 长任务按进展与预算压缩，在同一轮运行中继续，不通过取消、隐藏消息另起一轮。
- 明确的工具名单优先；短任务不强制写计划，内存会话不要求创建归档目录。

完整配置、导出大小边界及迁移说明见 [随包文档](../packages/agent-app/docs/context.md)。源码职责见 [架构说明](architecture/README.md)。
