# 简体中文汉化边界说明

状态：已实施并完成补漏复核（2026-09-16）。本文只保留当前边界与验证结论。

## 已汉化范围

- CLI 帮助、命令描述及产品提示；命令名与参数仍使用原标识。
- 交互终端的启动帮助、资源分组、设置/模型/会话选择器、状态提示和快捷键说明。
- 推理设置统一显示为“推理强度”，级别显示为关闭、极低、低、中、高、超高、最高；选择与搜索支持中文，实际枚举值不变。具体可用级别由模型决定，不再对所有模型承诺相同的 Token 预算。
- 底栏使用输入、输出、缓存读/写、命中、上下文等标签；项目内 TPS 扩展显示平均输出速率。该速率按整次执行耗时计算，不代表纯模型解码速度。
- 设置项的布尔值和内置模式值通过显示映射汉化；保存值和回调参数保持不变。
- HTML 导出的页面控件、会话树与统计标签；折叠历史推理显示“推理内容（已折叠）”，避免误报仍在生成。
- 根 README、SECURITY、agent-app README 及入门文档。

## 保持不变

- 命令、选项、环境变量、路径、退出码、快捷键绑定。
- 配置键、内部枚举、模型/服务商 ID、工具名、系统与工具提示词。
- 用户输入、模型回复、模型返回的推理内容与底层原始异常。英文原文并不等于界面漏译。
- JSONL/RPC/SDK 数据结构与事件名；HTML 内嵌数据保留原始值。
- 许可证、归属声明、品牌检查白名单、第三方库与已发布 CHANGELOG。

## 显示与逻辑边界

- 凭据选择依据模型目录中的实际模型，不再匹配警告文案。
- 登录取消依据专用错误类型或中断信号，不再比较“已取消登录”字符串。
- 仍需同步维护的局部映射：main.ts 的扩展加载提示识别、确认/分支总结选项、项目信任及 HTTP 超时选项。修改这些标签时需同时核对返回值处理。
- 不引入额外国际化框架，不改变 Agent 循环、模型请求或会话格式。
